技术栈

环节用了什么为什么
页面原生 HTML / CSS / JS任务书限制；想把 DOM 和请求讲清
后端Node 22+ / Express 4生态熟，SSE 转发最省事
存储SQLite（node:sqlite 内置）零原生编译，部署不会卡在 node-gyp
流式SSE（text/event-stream）单向推送，不用 WebSocket
模型OpenAI 兼容协议换平台只改三个环境变量
工具function calling让模型能"动手改数据"，不只是会聊

三个可以现场讲的地方

  1. [讲解点 A] server/utils.js 的 catchAsync：为什么 Express 4 里 async 抛错会杀进程。
  2. [讲解点 D] server/routes/chat.js 监听的为什么是 res 的 close 而不是 req。
  3. [讲解点 E] public/app.js 用单一 state.list.status 驱动三态渲染，而不是三个 if 各改各的 DOM。
